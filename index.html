Data and methods

    RAM includes estimated weights, 20% runtime overhead and an FP16 key/value cache for the model's supported context. Models supporting over 200,000 tokens use half their supported context for this estimate. KV cache is calculated from each model's Hugging Face config (layers, key/value heads and head dimension). Actual peak RAM varies by inference engine, cache dtype, context contents and other allocations. Results without verified parameter count, precision or context metadata are omitted. BFCL scores are shown only for exact repository matches; different benchmarks are not directly comparable.
