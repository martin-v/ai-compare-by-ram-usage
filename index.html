Data and methods

    RAM is estimated as parameters x bytes per weight x 1.2. Actual needs vary with runtime, context length and KV cache; this is not a measured peak-memory result. Benchmark scores come from their linked sources and are not directly comparable across different tests. A variant is shown only when its parameter count and precision are known.
